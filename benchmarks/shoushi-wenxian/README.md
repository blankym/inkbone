# 《收尸问仙》第 1 章的版本记录

这里记录作者自己的小说《收尸问仙》第 1 章前后十几个版本的写法变化和 AI 检测结果，用来回答一个问题：检测分和读起来好不好，是不是一回事。

- `manifest.json`：每一版用了什么写法、哪个版本的 skill、哪个模型（知道的才填），以及朱雀检测的实测结果和来源。`observations` 里记了分数波动的原始数值。
- `project-rules.json`：这本书的项目层规则，可以当作写项目层规则的例子。

公开仓库只包含这两个文件。小说正文、全书台账和检测报告是作者未发表的作品，不公开；依赖它们的回归测试在公开仓库里会自动跳过，同样的逻辑有不依赖这些文件的测试覆盖。
