# 流派剧本卡：快节奏爽文 / 系统脑洞 / 轻小说 (`light-fantasy`)

> 按需加载：仅当项目 `genre` 为 `light-fantasy` 时读取。

## 核心逻辑
读者看的是**明快反馈、信息差反转、外挂与现实环境的精妙碰撞、以及持续不断的小爽点兑现**。切忌把轻快写成空洞灌水，也切忌把严谨的苟道压抑节奏硬塞进来憋屈读者。

## 快节奏与爽点法则
1. **两压一扬不拖过夜**：被轻视、质疑或针对后，尽快在当前小单元内通过反差出手、系统兑现或信息差完成爽感落地；反派挑衅不过三轮就见分晓。
2. **外挂要放在“最需要它”的环境**：拿到奖励自己闷头看面板不算爽，必须放进周围人不信、恰巧卡死局面或需要当众交作业的场景里引爆反应。
3. **自然吐槽与反差感**：允许轻快口语与适当内心吐槽，但严禁枯燥的系统参数大段抄说明书，也禁绝陈旧“恐怖如斯/此子断不可留”老派打脸套话。

## 场景载体与节奏
- **落地颗粒**：系统面板精简一行提示、任务倒计时、榜单排名变动、直播弹幕/围观反应、道具词条反差用途。
- **爽点释放**：小投入撬动全场震惊、规则外玩法破解死题、众人以为要翻车时反手把奖励揣进兜里。
- **章尾钩子**：刚领完奖励面板突然跳出异常新任务、全场刚夸完下一位正主刚好推门进来、系统提示暴露某个熟人的隐藏身份。

## 禁止漂移
- 禁止面板提示写得像长篇政府公告或 API 文档；
- 禁止流水账式连环打脸而不改变角色处境与新筹码（爽点落地后应顺势带出下一个外部约束或代价）；
- 禁止全篇只剩配角轮流“倒吸凉气/震惊失声”而没有真本事与新信息推进。
