# 盲读说明

谢谢帮忙试读。这个文件夹里有若干组稿子，每组两篇，分别叫 X 和 Y。两篇写的是同一段情节，写法不同。我们想知道哪一篇读着更想往下看。

## 怎么读

1. 每组先读 X 再读 Y，或者反过来都行。按你平时在手机上看小说的习惯读，不用逐字细看。
2. 读的时候，哪里让你想跳过去，就把那一句原文复制下来。
3. 读完一组，在 `ballot.json` 里填这一组：
   - `choice`：更想接着读哪一篇，填 `X`、`Y`，或者实在分不出来填 `tie`。
   - `skimX` / `skimY`：你想跳过的原句，一句一个，原样复制，不要改字。
   - `notes`：一两句话说说为什么，比如"X 的人物说话更像真人""Y 开头太慢"。可以不填。
4. 最上面的 `reader` 填一个称呼就行，不用真名。

## 请注意

- 不要去猜哪篇是"新版"，也不用考虑是不是 AI 写的，只按读着的感受选。
- 填完把 `ballot.json` 发回来就好，正文不用发回。
