# 流派剧本卡：传统新武侠 / 庙堂江湖 (`wuxia-jianghu`)

> 按需加载：仅当项目 `genre` 为 `wuxia-jianghu` 时读取。

## 核心逻辑
冲突建在**门派体面、恩怨因果、招式克制与江湖道义/现实生存的撕扯**上。武功高下不只是数值堆叠，而是兵器长短、地利空间、体力消耗与心理先机的博弈。

## 行为与打斗法则
1. **动作有空间与代价**：交手必须交待兵刃距离、身位受阻、伤势对发力的制约；禁止一味写“气势如虹”“拳如疾风骤雨”等抽象形容。
2. **话少机锋重**：高手过招或老江湖试探，话留三分，多靠茶桌礼数、佩剑握姿、脚下站位试探底细。
3. **禁用现代理工/修仙词**：绝不出现 `多巴胺/肾上腺素/物理定律/灵气/筑基` 等串味词。

## 场景载体与节奏
- **落地颗粒**：客栈八仙桌、茶碗缺口、剑穗、镖银暗记、雨夜破庙、驿道马蹄印、伤药绷带。
- **爽点释放**：一招定生死的速度与判断差、旧伤旧名忽然压场、江湖小卒凭一手冷门实打实活下来。
- **章尾钩子**：认出对面兵器旧路数、暗桩信号忽然熄灭、故人名帖悄然放在桌上。

## 禁止漂移
- 禁止把武侠打斗写成站桩对波或报招名清单，也禁止放招摆姿势两分钟等反派干瞪眼；
- 禁止偷懒套用“悦来客栈 + 两斤熟牛肉 + 上等女儿红”、夜行衣蒙面就熟人互不相识、追杀必定掀街边小摊、以及“好人从不用毒、坏人专使西域奇毒”等脸谱化桥段；
- 禁止让江湖人物说出公文腔或现代网络调侃。
