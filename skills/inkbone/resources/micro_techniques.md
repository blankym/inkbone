# 网文核心微公式与诊断反查 (Micro Techniques & Diagnosis)

> 按需加载：仅在 Stage 1（节拍规划）、Stage 3（审读）或大修定位症状时读取。只收可执行的动作公式，不讲空洞理论。

---

## 一、 期望与节奏底层公式

### 1. 动作—反应“两压一扬”单元
- **基本单元**：`动作 + 反应` 缺一不可。只压不扬没爽点，只扬不压没铺垫。
- **标准节奏**：第一对动作-反应向下压主角（质疑、剥削、盘查、被看扁，攒期待）；第二对动作-反应向上扬（凭信息差/底牌反手破局、震慑、获利落地）。
- **爽点落地条件**：收益或出手必须放进“周围环境真正需要它、或者反派自以为胜券在握”的不平衡场景里，主角自己闷头捡宝没人见不到不构成爽感。

### 2. 期待感三要素（不平衡）
- **场景不平衡**：开头 350 字内用一个反常动作或危机打破日常均势（异常尸首、退婚、停职、异常账目），让读者等待新平衡。
- **身份与信息差**：让场上对手轻视/误判主角（或主角与读者知道底牌、对手蒙在鼓里），期待集中在“双方什么时候正面碰撞”。
- **黄金五章梯度**：`第1章 异常入局并绑定生死代价` → `第2章 暗流试探与微操周旋` → `第3章 兑现第一笔实在筹码 + 立硬倒计时锁` → `第4章 走出初始封闭点暗布反制` → `第5章 干净结算首轮危机并推开主线`。

### 3. 压迫感物理化公式
不要用形容词写“反派很可怕 / 气氛很压抑”，固定用这三件套之一：
1. **物理屏障落差**：反派周身异象隔绝风雨/环境，主角半身泡在泥水或暗处低头避锋。
2. **资源/成本碾压**：反派随手丢出的消耗品，抵得上主角几个月身家，却只当作一次用完即焚的垃圾。
3. **退路封死物证**：先写门外从里闩死、出口被堵、暗器倒扣袖中，让顺从同样必死，再把主角逼进反击。

### 4. 对话器物潜文本法则（禁直球喊动机）
人物试探、敲打、求情或推拒时，禁止张嘴直白喊出裸露动机或情绪标签；将真实意图寄托在具体日常器物、账目、茶食或手头活计上，让对手从器物反常处听出利害变色，严禁事后补旁白解释“他听出了弦外之音”。

### 5. 高潮余韵与“战利品三件套”法则
- **高潮余韵**：大冲突落幕后严禁立刻硬切新地图/新事件，必落 1～2 笔外部回响锚点（场边席位失态、悬赏榜单变动、既得利益重新洗牌），把主角拿下的分量坐实。
- **战利品三件套**：战后清点杜绝报菜名式数值流水账，按三层配比设计：① **1 件即战力转化物**（当场补齐短板或直接用于下次破局）；② **1 件跨地图锁死线索物**（眼下打不开或缺后续辅材，天然牵引下阶段主线）；③ **1 批人情流通置换物**（用于变现灵石/资金或转赠结交关键盟友）。

### 6. 强对抗“二八烘托”与假动作反转
- **二八烘托配比**：高烈度交锋或立威名场面，80% 笔墨写环境物理异变与场边二三流标尺人物的失态反应，仅 20% 写致命落点本身；严禁连续报招式名与五颜六色光效对轰。
- **假动作预期违背**：关键博弈破局前，先顺理成章抛出常规解法 B 诱使对手与读者信以为真，落子瞬间亮出早已暗扣在手底的杀招 C。

### 7. “纵横双坐标”与三维境界差
- **纵横双坐标**：非纯战斗或慢热晋升线（权谋、经商、才学、科举等），必须把**纵向位阶晋升**（身份品秩升级）与**横向同辈榜单/席位对比**咬合，才持续出爽感。
- **三维境界差**：跨大等级或阶层时禁止只涨战力数值，必须同步落在**杀伤威慑 + 日常收支/消耗量级 + 制度礼遇特权**三个切面。

### 8. 伏笔“一物多用”与换地图前置坐标
- **伏笔不当纯闲笔**：埋下的异常器物、人脉或习惯，最好在当下就能承担一次实际功能（日常用器 → 破局/作案工具 → 后续破案物证），而不是硬塞一句“三十章后才用得上”的突兀提示。
- **换地图提前锚定**：切大地图前几章，先借对话、账单、缺味主药或过客传闻把新地名与新规矩递出来，避免当前危机刚解就凭空跳去陌生新副本。
- **周期回响与控数量**：同期活跃伏笔不宜摊得太散；跨卷长线伏笔每隔一段需给一次自然提醒，别拖过读者记忆周期才突然翻旧账。
- **外挂随人同步解锁**：若主角带有金手指，避免一开篇做成“什么都能换、什么都能查”的万能礼包，让核心权能随境界或代价逐步开启，并始终围绕主角自身选择运转。

## 二、 章首与章尾钩子定式

### 章首 4 类高留存切入
1. **带代价的日常职能切入**（适合慢热/苟道/职场）：正在干本职活计，顺带撞出一条不合规矩的异常物证。
2. **未完成动作或突发打断**：动作推进到关键半拍，突发外力砸入（拍门、传讯、警报）。
3. **倒计时压顶**：开头直接亮出剩余时限与缺口资源。
4. **反常细节或反差对话**：一句不合常理的话直接抛在第一行（须立刻锚定说话人与处境，避免无主悬空）。

### 章尾 5 类强钩子定式（禁写“殊不知/命运齿轮”）
1. **认知反转型**：刚看清死者或对手真实身份，立刻露出与主角直接挂钩的物件或死局。
2. **物理贴脸型**：门栓被挑起一半、脚步停在门槛外、致命物证当场掉出来。
3. **信息截断型**：外挂/密信刚照出幕后黑手的一句指令或全员死期，戛然而止。
4. **两难代价型**：两个选项都必须割肉或冒死，章末停在动手前那一息。
5. **收获超预期余韵**：破局后清点战利品，突然摸出一件超出当前阶段认知的异物。

## 三、 大修症状反查表（旧稿读感不对时先对表）

| 读者/审稿反馈 | 先查哪一环 | 常见问题 | 修改方向 |
| :--- | :--- | :--- | :--- |
| **拖沓、水、不知道这章在干嘛** | 本章状态变化 | 七步生理流水账、礼貌寒暄、没有目标或推进 | 砍至“晚进早出”；删除不改变信息/关系/风险的过场段 |
| **爽不起来、“就这？”** | 压与扬配比 | 前面压迫或代价铺垫不够，或破局时缺少旁观反馈 | 补齐死局铁证与对手预期落差，放大获益或反杀后的局势翻转 |
| **主角憋屈、无脑找死** | `character_logic_suicide` | 顺从就能活却偏要去查秘密；叙事站在反派或旁白视角 | 先塞进“不反抗照样必死”的封路铁证，再动手破局 |
| **“又是这一套”、模板疲劳** | 连续三章核心梗 | 同一套盘查、同一套借口、同一套震惊模板连用 | 换场景载体、换受阻方式、换对手施压筹码 |
| **换地图后突然不好看了** | 跨地图旧线延续 | 进了新地方就把旧仇、旧目标、旧伏笔全清零 | 让至少一条旧线索或旧因果跨地图直接卡住新局面 |
| **新读者看懵、插不进情绪** | `cold_reader_*` | 境界/能力数字没有标尺，未绑定眼前人物下场 | 在首次出现处用 1～2 句具体人事写明差距与后果 |
| **干瘪像提纲/大纲扩写腔** | `overcompressed` / 抄细纲 | 动笔前读了大纲表没读正文语态；每句都按提纲要点报幕 | 重读上章结尾与范文语态，合并同重心碎句、恢复必要因果连接 |
| **对白干巴、像审讯汇报或直球吵架** | 对话潜文本与单段锚定 | 角色张嘴直接报动机，或连续多行纯引号无动作支点 | 把直白诉求改成借器物/规矩敲打；每段对话只锚定一个动作主体 |
| **主角像傀儡，或装傻把读者也憋走** | 主动态 & 防“闷坑” | 全章被动接招（反应态），或藏拙时连读者也一并死瞒到底 | 每章至少一次主动设局选择；伪装时给读者留一处可见物理微锚点 |
